# 铁路轨道几何缺陷整治与复测平台

基于Vue3、Vuetify、Pinia、Vue Router、Apollo Client、GraphQL、Vite和TypeScript的独立前端工程，使用Canvas绘制里程图。业务数据本地持久化。

## 功能

- 区段、里程、轨距、高低、方向和三角坑检测数据。
- Canvas里程分布、超限点定位、缺陷三角标记和缩放。
- 缺陷筛选、批量派工、工区责任和重复缺陷关联。
- 打磨、捣固、更换、垫板调整等整治记录，复测轮次与关闭校验。
- 正式限速与临时限速冲突联查，区段版本递增。
- **离线补传回传**：无网区段整治、复测、关闭、派工、限速操作先留本机发件箱，网络恢复后按缺陷版本/区段版本合并；两班组并发提交同一缺陷时后到不覆盖，冲突转待复核，支持“采用服务端 / 保留现场重传”两种裁决。
- **失败保留与重试**：逐条入库即时落盘，中途网络失败只中断后续条目，已入库部分保留；指数退避自动重试并可手动重试；重启后待回传内容从持久化恢复不丢失。
- **关闭联动限速重算**：一级缺陷关闭后按未关闭一级缺陷数量重算区段临时限速（仍有一级缺陷时维持/压低，全部关闭时解除），区段版本递增并在区段记录与审计中留原因。
- 完整审计和整治报告导出。

端口为`18466`。

```bash
npm install
npm run build
npm run dev
```

## 离线回传验证

```bash
npm run verify:sync    # 服务端：版本校验/冲突/失败保留/限速重算 20 项断言
npm run verify:store   # 本机：冲突转待复核/keep·adopt裁决/操作链平移 19 项断言
```

### 数据存放

- `gsb66:server`：模拟驻地权威库，按缺陷/区段版本做乐观锁校验，跨标签页通过 storage 事件同步，可开两个标签页模拟两个班组。
- `gsb66:local:<设备号>`、`gsb66:outbox:<设备号>`：本机现场库与待回传发件箱（按设备隔离，重启不丢）。
- “离线回传”页提供：模拟断网 / 8 秒网络抖动、对端班组直接写权威库（整治、复测合格/不合格、关闭、区段限速）、发件箱状态与冲突裁决入口。
